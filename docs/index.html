Install

Grab the binary for your OS, then install yt-dlp and ffmpeg.

Windows

Download YT Audio Downloader.exe → 
pip install yt-dlp
winget install ffmpeg

Then double-click the .exe to open the web UI.

Linux

Download yt-audio-downloader → 
pip install yt-dlp
sudo apt install ffmpeg

Then in terminal:

chmod +x yt-audio-downloader
./yt-audio-downloader

Use your distro's package manager if you are not on Debian/Ubuntu.

macOS

Download yt-audio-downloader-mac → 
pip install yt-dlp
brew install ffmpeg

Then in terminal:

chmod +x yt-audio-downloader-mac
./yt-audio-downloader-mac

Allow the binary in System Settings if Gatekeeper blocks the first run.
